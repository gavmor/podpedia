## 1. Summary

This experiment benchmarks two graph database backends for Podpedia's knowledge graph pipeline:

| Backend | Description |
|---------|-------------|
| **MemoryGraphDB** | Pure in-memory Go implementation (maps + slices) |
| **SQLiteGraphDB** | SQLite-backed (in-memory, `modernc.org/sqlite`, pure Go, no CGo) |

## 2. Methodology

### Benchmark Parameters

| Parameter | Value |
|-----------|-------|
| `-benchtime` | 30s |
| `-count` | 30 |
| Iterations per variant | 30 independent runs |
| Operand scales | 100, 1000, 5000 nodes |

### Graph Topology

- **Scale N:** Insert N nodes, each with 2 properties (`index`, `name`)
- **Edges:** ~3N random directed edges (seeded PRNG, seed=42)
- **Snapshot:** Serialize full graph (all nodes + edges + properties)
- **Traversal:** Full BFS from `node-0`, visiting all reachable nodes

### Variants (12 total)

```
BenchmarkGraphSnapshot/MemoryGraphDB/scale-100
BenchmarkGraphSnapshot/MemoryGraphDB/scale-1000
BenchmarkGraphSnapshot/MemoryGraphDB/scale-5000
BenchmarkGraphSnapshot/SQLiteGraphDB/scale-100
BenchmarkGraphSnapshot/SQLiteGraphDB/scale-1000
BenchmarkGraphSnapshot/SQLiteGraphDB/scale-5000
BenchmarkGraphTraversal/MemoryGraphDB/scale-100
BenchmarkGraphTraversal/MemoryGraphDB/scale-1000
BenchmarkGraphTraversal/MemoryGraphDB/scale-5000
BenchmarkGraphTraversal/SQLiteGraphDB/scale-100
BenchmarkGraphTraversal/SQLiteGraphDB/scale-1000
BenchmarkGraphTraversal/SQLiteGraphDB/scale-5000
```
