# Podpedia

An automated podcast processing pipeline that ingests RSS feeds, downloads audio, transcribes content, and extracts structured data (guests, companies, themes) using local LLMs.

## Architecture

- **Language:** Go 1.26.1
- **CLI Framework:** cobra (spf13/cobra)
- **Build System:** Makefile + Go modules
- **Plugin System:** WebAssembly (WASM) via wazero/wasm-microkernel

## Project Structure

```
├── main.go              # Entry point
├── cmd/                 # CLI commands (root, run)
├── internal/            # Core pipeline logic
│   ├── kernel/          # WASM microkernel + adapter wiring
│   ├── pipeline/        # Pipeline orchestration
│   ├── protocol/        # Shared interfaces
│   ├── types/           # Data structures
│   ├── storage/         # Storage implementations
│   ├── transcription/   # Transcription support
│   └── llm/             # LLM integration
├── plugins/             # WASM plugin source (compiled to dist/plugins/)
│   ├── rss/             # RSS parser plugin
│   ├── downloader/      # Audio downloader plugin
│   ├── transcriber/     # Transcription plugin
│   ├── extractor/       # Entity extraction plugin
│   └── store/           # Storage plugin
├── dist/plugins/        # Compiled .wasm files (generated by `make plugins`)
└── Makefile             # Build orchestration
```

## Key Dependencies

- `spf13/cobra` — CLI framework
- `mmcdole/gofeed` — RSS parsing
- `cavaliergopher/grab` — Audio downloading
- `alitto/pond` — Goroutine worker pools
- `gavmor/wasm-microkernel` (tetratelabs/wazero) — WASM runtime
- `code.cloudfoundry.org/lager/v3` — Structured JSON logging
- `onsi/ginkgo` + `onsi/gomega` — BDD testing

## Usage

```bash
# Build the binary
go build -o podpedia .

# Build WASM plugins
make plugins

# Run the pipeline
./podpedia run --url <RSS_FEED_URL> --output <OUTPUT_DIR>

# Optional flags
./podpedia run --url <RSS_FEED_URL> \
  --output ./output \
  --plugins ./dist/plugins \
  --ollama http://localhost:11434 \
  --transcribe-url <WHISPER_ENDPOINT>
```

## Development

- Run tests: `go test ./internal/...`
- Build plugins: `make plugins`
- Full CI: `make ci`
