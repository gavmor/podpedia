# Product Guidelines

## Prose Style
- **Objective:** All entries in the encyclopedia should be written in a neutral, objective tone.
- **Concise:** Avoid filler; prioritize factual information extracted from transcripts.
- **Attribution:** Where possible, reference the specific episode and timestamp for key claims or data points.

## Data Standards
- **Standardized Tags:** Use a consistent set of tags for "Person", "Company", "Ideology", and "Business Model".
- **Markdown Formatting:** Use clear headers, bullet points, and front-matter metadata for all generated encyclopedia pages.
- **Schema:** Follow a fixed schema for JSON exports to ensure compatibility with downstream tools.

## User Experience (UX)
- **CLI-First:** The primary interface is a command-line tool. Output should be clean and informative.
- **Progress Tracking:** Provide clear, real-time feedback during long-running ingestion and transcription tasks.
- **Local-By-Default:** Ensure all features work offline once the feed has been downloaded.
